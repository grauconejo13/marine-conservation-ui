# Marine Conservation UI

A public frontend concept exploring marine conservation storytelling, species education, ecosystem threats, restoration efforts, and ways people can learn more.

This repository is a UI/portfolio demonstration and is separate from any production conservation platform.

## Planned focus

- Marine life and biodiversity
- Ocean and coastal threats
- Conservation and restoration efforts
- Educational storytelling
- Accessible, responsive frontend design
- Mock conservation data and interface concepts

## Stack

React + Vite

> Demo content should not be interpreted as live conservation data or an official conservation service.
